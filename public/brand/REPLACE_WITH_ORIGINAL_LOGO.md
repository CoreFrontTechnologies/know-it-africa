# Original Know It Africa Logo

The website is wired to use this single brand asset path everywhere:

```text
public/brand/know-it-africa-logo.svg
```

If you have the exact original PNG/JPG logo file from the designer, replace `know-it-africa-logo.svg` with the original exported logo and keep the filename/path consistent, or send the original file so it can be committed directly.

Do not add a different generated logo. The current SVG is only a code-native fallback because the original uploaded image file is not present in this repository filesystem.
